Devices check in when the app starts and every 6 hours. A pin gives one device its own version (upgrade or downgrade); empty follows the policy.

Policy

For each kind of device: which version it should run, and what it does about it. Pick an older version to downgrade.

DevicesVersionActionRunning now

Off: nothing happens. Ask: the app shows the update and the user installs it. Install automatically: installs when no call is on (Android still asks for one tap; iPhone and Mac can only show it).

Versions before 1.9.1 can't update themselves: a device downgraded to one stays there until it's updated by hand. Android can't downgrade at all (it would have to be uninstalled, which deletes its settings).
