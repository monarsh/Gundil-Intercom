Updates

The gateway asks its update server an hour after it starts and every 6 hours, and installs by itself when the server says Install automatically. Install installs the offered version now, also when the server says Ask. Every file is checked against the release's signature first. The gateway then restarts on the new version (sign in again).

Turn self-update on or off, or set another update server, in Settings.
